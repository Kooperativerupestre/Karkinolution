# "Done" Means Verified, Not "Looks Complete"

Do not tell Enzo (Koöperative Rüpestrën) something is finished unless you have run the relevant tests and they pass.
This project has been
"declared finished" and then reopened multiple times because more was found — that's fine when it's discovery, not fine
when it's an agent overclaiming status to sound productive.

State exactly what you verified and what you didn't. "I implemented X, ran the existing test suite, added N new tests
covering Y and Z, all pass" — not "X is done."
