# Biology Adapts to Core, Never the Reverse

Core = the models: Creature, Embryo, Genome, Corpse, Egg, and their peers. These define what an organism IS.

Biology = physiology and motors (instincts, planners, perception, attack, reproduction logic, brain) — what an organism
DOES.

Rule: biology code adapts itself to whatever the core models expose. It does NOT get to add a field, method, or state to
Creature/Embryo/ Genome/etc. just because a physiology or motor system needs it.

If a biology feature seems to require a core model change, that is a signal to redesign the biology feature around the
existing model — not a green light to touch the model.

The ONLY exception: the core model is undergoing its own independent update, unrelated to accommodating a biology
feature. If you can't name that independent reason, the exception doesn't apply.

When in doubt, don't touch the model. Flag it to Enzo and explain what the biology feature actually needs.
